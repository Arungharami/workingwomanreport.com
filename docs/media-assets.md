# Media Asset Convention

Store production assets under:

`public/media/weekly/YYYY-MM-DD-story-slug/`

Each weekly package should use:

- `hero/` for canonical story art
- `video/` for local captions, transcripts, and video references
- `social/` for vertical crops and platform-specific exports
- `thumbnails/` for YouTube, OG, and card images

Preferred minimum sizes:

- Hero: 1600 x 900
- Open Graph: 1200 x 630
- YouTube thumbnail: 1280 x 720
- Instagram feed: 1080 x 1350
- Vertical video: 1080 x 1920

Do not add fake photographs. Do not migrate or publish photographs until rights
are confirmed. Every production image needs meaningful alt text.
